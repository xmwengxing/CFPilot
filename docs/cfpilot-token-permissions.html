⚠️ 不要用「Edit Cloudflare Workers」预设模板

该模板只给 Workers Scripts / KV / Routes / Tail / R2 + Account Settings，不含 Pages Write —— 用它部署会在创建 Pages 项目时报 403。

对应关系：每一项权限对应哪些接口

调用的接口需要的权限用途
GET /accountsAccount Settings · Read读取账号列表
…/storage/kv/namespaces…Workers KV Storage · Write建 KV、读写清单与 CONFIG
…/pages/projects…Pages · Write建/删项目、传内核、绑 KV、配变量、绑域名
GET /accounts/{id}/tokens/verifyAccount API Tokens · Read显示 Token 有效期（可选）

操作步骤

  1. 打开 Manage Account → API Tokens → Create Token → Create Custom Token
  2. Token 名称填 CFPilot，权限只勾上面「必需权限」那 3 项
  3. Account Resources 选 Include → 你的账号（或 All accounts）
  4. Zone Resources 留空（不要选任何 Specific zone）
  5. IP 地址过滤留空，TTL 按需（留空 = 不过期）
  6. 创建后复制 Token，填进 CFPilot 的「Cloudflare 凭据」页

验证权限（只读探测，不会改动账号）：
npx -y cfpilot@latest token --check
