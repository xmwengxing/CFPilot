🔗 链式代理（自建落地节点）

            

              在私有 VPS 装一个带口令的 SOCKS5 落地节点，
              流量走 客户端 → Worker → VPS → 目标站。
              目标站看到 VPS 出口，非 Cloudflare 机房 IP。
            


            

              

                
                
              

              

                
                
              

            


            

              
              
            


            


            

              · 需要本机有 ssh 客户端且已配好密钥。

              · 无密钥：点「复制命令」在终端里执行 —— 终端 ssh 提示输入密码。

              · 脚本会装 sing-box、生成随机口令、起 systemd 服务，仅支持 Debian/Ubuntu/CentOS 系。

              · 运行后输出 socks5://用户:口令@IP:端口，粘到面板「出站与高级」→ SOCKS5。

              优选IP流程说明
              

                整体流程（四阶段，全部基于真连接校验，不采信单纯 TCP 延迟）：

                阶段一 · TCP 握手初筛 —— 从 Cloudflare 网段按「实测可用率加权」采样候选，
                测 TCP 握手延迟，剔除完全不通的 IP；

                阶段一之二 · TLS 握手筛选 —— 用你的域名作 SNI 完成完整 TLS 握手，
                淘汰「能建 TCP 但握手极慢 / 失败」的 IP
                （这是优选 IP 导入客户端后延迟 -1 的主要根因）；

                阶段二 · 两层校验 —— 第一层 WebSocket 101 协议升级：
                排除 Enterprise 专属 IP 与 SNI 阻断；
                第二层 响应体内容校验：发 PING 验证数据面真实响应，
                拦截「握手能过但实际不可用」的假活 IP；

                阶段三 · 真实下行测速 —— 多连接 + 丢弃预热期，
                按稳态吞吐排序（单窗口峰值会虚高，不作为排序依据）；


                补充说明：

                · 最终结果按 /16 网段轮流取优，避免整批集中在一个网段、
                一段路由拥塞就全军覆没；

                · CFPilot 实例走自有探针端点测速；其它项目回落公开测速地址；

                · 勾选「跳过测速」时退化为纯延迟排序（速度列显示 —）；

                · 机房国家筛选在阶段二之后生效（机房码只有 101 响应里才有）；

                · 每次优选成功自动留底到下方「优选历史」，可多选复制、二次复测可用性；

                · 结果输出在下方，可复制到 Web 面板的「手动优选 IP」框，或点「增量回填 / 覆盖回填」直接写入。

              CFPilot 的图形化部署与维护工具。功能与命令行版
              cfpilot deploy / cfpilot scan 一致，
              适合不接触命令行的用户。
            

            

              首次部署流程

              1. 在「凭据」页填写 Token 并保存，「当前使用」中选中账号（系统识别到暂无CFPilot实例）

              2. 切换到「部署」页，选择「自动判断」，输入面板密码（不填则随机），点击「开始部署」

			  · 运行日志显示部署成功后的相关信息，请手动保存备查


			  Web 面板

			  1. 查看运行日志或点击「查看面板凭据」获取面板地址，浏览器中打开，输入登录密码进入控制台

			  2. 「运行概览」页点击「复制订阅链接」，导入代理工具即可遨游全球网络

			  · 默认分配 30 个节点 = 优选域名 10 个 + 官方优选 IP 20 个


			  优选 IP

			  1. 在「优选」页点击自动识别，其他保持默认，点击「开始优选」，等待优选结果

			  2. 「增量回填」：保留面板里已有的优选 IP，只补入本次新结果，订阅直接生效

			  3. 「覆盖回填」：清空面板优选池后写入本次结果

			  4. 「复制结果」：Web 面板打开「节点来源」，手动指定 IP 中粘贴结果，保存并应用

			  · ⚠️「覆盖回填」会清空原有的手动指定 IP；只想加几条请用「增量回填」

              · 优选 IP 稳定且短期不会失效，无需每日优选；节点测试延迟 -1 请再次测试


              升级内核

              1. 在「凭据」页「当前使用」中选中账号（系统自动识别 CFPilot 实例）

			  2. 唯一 CFPilot 实例：「部署」页点击「检查状态」，提示版本差异，点击「更新到最新内核」按钮

			  3. 多 CFPilot 实例：「凭据」页选择本次部署使用的 KV，其他同上

              · 订阅地址、面板密码、面板路径、WS 路径、UUID 均保持不变


              关于 CFPilot

              CFPilot 采用双项目部署一对实例：控制面（Web 面板）+ 数据面（流量转发），
              实测稳定无1101、无8000119，支持在触发 CF 限制时进行无损更新部署

              不建议在同一账户下部署多个 CFPilot 实例；若确有需求：创建新的 KV，选择该 KV 后部署第二对

              本项目已支持数据面 Workers 形式部署（新手建议使用默认 Pages）
            

          

          
          

            
📖 使用教程（点击展开）


            

              ① 盲中继 / 云监测台部署（所有版本）
              

                
盲中继让无公网 IP 的设备经 Cloudflare 边缘完成首次发现与保底连通；云监测台查看节点心跳。与代理实例完全独立。

                

                  1. 准备令牌

                  · 「凭据」页保存 Cloudflare Token。额外权限：Workers Scripts / Edit、Durable Objects / Edit、D1 / Edit、Pages / Edit；绑自定义域还需 Zone & DNS / Edit。

                  2. 部署

                  · 「部署」页 →「盲中继 / 云监测台」标签 → 填域名（必填，workers.dev 国内被污染）、Worker 名、监测台密码。

                  · +mesh 版可点「填入组网配置」把结果自动带入「组网」页。

                  3. 使用

                  · 日志给出 WSS 端点与监测面板地址；监测面板只读，查看节点在线状态与心跳。
                

              

            


            

              ② 异地组网（仅 +mesh 版）
              

                

                  把两台或多台设备连成一个私有网络，彼此用虚拟 IP 互访，无需公网 IP。
                  优先 UDP 直连（快），质量差时自动切 WSS 中继（稳），恢复后回切。以 A / B 两台为例。
                  每个填写项的含义把鼠标停在字段名的 ⓘ 上看气泡说明。
                

                

                  字段速查（★必填 / 自动 / ○可选）


                  自动 本节点 ID / 隧道密钥：本地身份密钥派生，只读；

                  ★ 网络名：例 my-home（两端一致）；

                  ★ 密钥PSK：例 mysecret123456（两端一致）；

                  ★ 本节点虚拟 IP：例 10.97.0.1（A）/ 10.97.0.2（B，同一网段、末位不同）；

                  ○ UDP 监听：默认 0.0.0.0:51820；○ TUN 名：留空即可；

                  ○ 盲中继域名 / 房间：由「填入组网配置」带入，UDP 无法直连时兜底，可选但建议。


				  组网流程
                  1.（可选）部署盲中继：见上方「① 盲中继部署」，部署后点「填入组网配置」自动带入 WSS 信息。

                  1.5（可选）自建服务器中继：在「高级选项 → 服务器中继」填服务器公网地址，点
                  「生成服务器部署命令」后在服务器执行，再把输出粘回「粘贴部署输出回填」，NodeId / 地址 / 令牌自动填好。

                  2. 设备A 展开「邀请链接」点「生成邀请链接」后复制链接，点「启动组网」。
                  空白配置会自动创建网络名、随机密钥与虚拟 IP。链接含明文密钥，勿公开。

                  3. 设备B 在「邀请链接」输入框粘贴邀请链接 → 点「启动组网」。

                  4. AB两端提权服务自动建虚拟网卡并运行，首次运行弹出系统授权框请点「允许」。
                  停止点「停止组网」；托盘右键也能启停、看节点列表。

                  5. 验证：命令终端互 ping 虚拟 IP（如ping 10.97.0.2），有延迟/无超时即成功；「网络拓扑」显示节点与流量。

                  连接失败速查：网络名 / PSK 是否两端一致 → 对端地址是否可达 →
                  防火墙是否放行 UDP 端口 → 同机多节点是否用了不同端口和 TUN 名。


				  三平台：Windows 双击 setup.exe；Linux sudo dpkg -i cfpilot-mesh*.deb；
                  Android 装独立「CFPilot Mesh」App（VPN 授权免 root）。

                

              

            


            

              ③ CFPilot 代理实例部署（所有版本）
              

                

                  首次部署：「凭据」填 Token 选账号 →「部署」自动判断 → 面板密码（不填随机）→ 开始部署；保存日志里的地址 / 密码 / UUID / WS 路径。

                  优选回填：「优选」开始优选 →「增量回填」补新 IP（保留旧的）；「覆盖回填」会清空手动指定 IP。

                  升级内核：「部署」检查状态 → 有新版时更新；订阅地址 / 密码 / 路径不变。
                

              

            

          


          

            
🔒 安全说明

            

              API Token 与面板密码仅写入本机
              本机数据目录，不会上传到任何服务器，
              也不随安装包分发。


              工具的出境网络请求仅三类：

              · api.cloudflare.com —— 部署必需，令牌仅用于该请求的 Authorization 头

              · 你自己的域名 —— 优选阶段的 101 握手校验

              · 你主动点击的官方链接 —— 以系统浏览器打开


              不存在「把令牌发到第三方」的路径。可随时点击「删除本地账号/凭据」清除。
