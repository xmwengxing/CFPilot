⚡ 一键优选并回填

后台跑一次完整的真连接优选，并把结果直接写回面板的「手动优选 IP」。 与托盘菜单里的「一键优选 IP」是同一个后端接口，跑完会弹系统通知。

耗时与手动优选相同（通常几分钟），期间界面照常可用。

⚡ 本地真连接优选

用自己域名做 TLS 握手 + WebSocket 101 + 响应体内容三层校验，只保留真正能连通且数据面在响应的 Cloudflare IP，运行可获得 IP 列表

· 建议使用自定义域名，*.pages.dev 生产链接可能被阻断
· 点「自动识别域名」：优先填入数据面自定义域名，没有则填入 pages.dev

· 必须与实际 WebSocket 路径完全一致，否则无法优选 IP
· CFPilot项目：部署后日志内复制，或点「自动识别 WS 路径」从项目内读取后填入
· 其他项目（不保障有效）：根据实际填写，若根路径可只填 /

· 按住 Ctrl / Shift 多选或取消， 不选则按采样数跑全量测试
· 若结果没有出现候选国家，请增加「候选采样数」

· 建议 10~20，过多增加请求没有实际意义
· 端口固定 443——其他端口请在web面板中配置（不推荐）

· 建议 6556（默认），不宜超过23000

· 留空即可，工具自动决定：
· 自定义则强制用指定地址（大文件测试可自填）

· 建议 3，单条 TCP 连接受拥塞窗口限制，测不满真实带宽

· 建议 5~8，太短会被 TCP 慢启动拉低（前 1 秒的样本会被丢弃）

阶段二两层校验：
· 第一层 WebSocket 101 握手 —— 排除 Enterprise 专属 IP、SNI 阻断； 第二层 响应体内容校验 —— 发 PING 验证数据面，拦假活IP
· CFPilot → 自有探针端点 → 自身路径测速； 其它项目 → 公开测速地址测速
· 勾选「跳过测速」退化为纯延迟排序（速度列显示 —）
· 勾选「不回填」时结果在下方显示，复制到web面板「手动优选 IP」框

⚠️ 运行前请关闭所有代理工具（Clash / Mihomo / v2rayN / sing-box / Surge 等）， 包括 TUN 模式与系统代理

如果必须开代理，请把本程序加入直连/绕过名单， 点「检测网络环境」可以确认当前系统是否处于干扰/代理状态

📘 这是什么

CFPilot 的图形化部署与维护工具。功能与命令行版 cfpilot-deploy / cfpilot-scanner 相同， 适合不碰命令行的用户。

三步部署
1. 在「Cloudflare 凭据」页填 Token 并保存，点「检测账号」，再点「刷新 KV 列表」
2. 在下拉框里选一个 KV（带 ● 的是已有实例），移至一键部署页点「开始部署」
3. 在「本地真连接优选」页填上一步得到的数据面域名，跑一次优选，把结果粘贴到面板的「手动优选 IP」
4. 优选IP可能失效，在节点不稳定时可再跑优选，无需每天进行

更新升级
选择「更新现有部署」：选同一个 KV，工具识别本项目，复用 UUID 与 WS 路径， 客户端订阅地址保持不变。

关于CFPilot
CFPilot采用双 pages 项目部署一对实例：控制面（web面板）+ 数据面（流量转发）， 实测稳定无1101，支持触发CF限制时进行更新部署
不建议同一账户部署多个CFPilot实例！若必须：点「新建 KV」，选择该 KV 后部署第二对实例
本项目暂不支持 worker 形式部署

🔒 安全说明

API Token 与面板密码只写在本机 ~/.cfpilot-gui/secrets.json，不会上传到任何服务器， 也不随安装包分发。

工具的出境网络请求只有三类：
· api.cloudflare.com —— 部署必需，令牌仅用于该请求的 Authorization 头
· 你自己的域名 —— 优选阶段的 101 握手校验
· 你主动点击的官方链接 —— 用系统浏览器打开

不存在「把令牌发到第三方」的路径。随时可点「清除本机凭据」删除。

❓ 常见问题

面板打不开？面板路径是随机生成的，部署日志里会打印。

优选结果全是 -1？检查域名与 WS 路径是否和客户端一致，端口是否为 443 等 TLS 端口。

提示「版本相同已跳过」？说明线上已是最新版本，无需重新部署；需要强制更新就勾选「强制重新部署」。

部署失败？看下方日志里的具体错误；权限问题可对照「凭据」页的权限说明。
