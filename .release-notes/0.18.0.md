## 新增

- IP 质量报告新增公开信誉库评分与归属信息，可查看欺诈分、风险档位、机房/代理/VPN/Tor 标记、黑名单命中与国家/城市/ASN/ISP
- IP 质量报告新增四个使用场景的适配判定：常规浏览、账号登录、流媒体与 AI、风控严格站点
- 优选扫描新增按 XHTTP 传输探测，可单独验证或与 WebSocket 取交集
- 桌面版与内核面板左上角补上版本号

## 修复

- XHTTP 节点在 Cloudflare 边缘上全部连不上的问题，改为分包上行模式后恢复可用
- XHTTP 上行暂存加上隔离体内存上限，避免异常请求耗尽内存
- 历史记录里的质量报告按钮改为只读查看，不再误触发重复检测
- 部署时环境变量与 KV 绑定合并为一次配置请求，减少平台侧的发布次数
- 配置读取遇到缓存未同步时不再自动重写凭据，避免订阅链接与连接凭据被意外重置

## 优化

- IP 质量检测的信誉与归属查询改为并发，耗时明显缩短
- 质量报告的信誉、风险、标记、黑名单与归属各项补充了说明提示，看得懂各项含义
