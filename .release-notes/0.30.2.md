## 新增

- Docker 版：一条命令跑起来，设置与凭据存在数据卷里，重建容器不丢
- 安卓版安装包：手机直接装，界面与桌面版一致

## 修复

- 修复点击「添加并保存」后没有任何反应、也没有任何提示的问题
- 修复 Docker 版启动后无响应的问题
- 修复 Docker 版服务在容器外访问不到的问题
- 修复安卓版一打开就崩溃的问题
- 修复界面显示的凭据与日志路径与实际不符的问题
- 修复界面版本号显示为开发版的问题
- 修复手机上 Token 输入框被挤没、无法输入的问题

## 优化

- 接口出错时日志里会记下原因与接口路径，不再只有一片空白
- Docker 版与安卓版默认只允许本机访问，需要时可手动放开局域网
- 安卓版同时支持 64 位与 32 位设备
