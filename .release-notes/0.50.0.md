## 新增

- 出厂内置一批实测可用的反代入口兜底：零配置即可稳定访问 Cloudflare 网段站点（含 X 手机 app）
- 反代优选终检升级：逐个校验网址实测转发，被站点边缘规则拦截的入口自动剔除
- 应用更新自动化：检查更新后自动下载到缓存，下载完成出现「重启并更新应用」按钮，一键替换主程序并重启
- 控制面顶部横幅新增「内核检查」按钮：自动检查官方内核通道，有新内核时按钮变化并给出两种更新方式
- 面板「自定义反代入口池 / 固定落地 IP」只显示自己填写的条目，出厂兜底隐形生效
- 出站拨号时序参数可配置：连接超时 / 总预算 / 静默窗口 / 反代换入口上限，均可在面板或环境变量调整
- 按目标域名自定义出站策略：固定静默窗口或禁止假活重拨（与固定落地 IP 同一输入框）
- 全部类型的出站候选带健康记忆：连续失败的入口自动冷却避让，恢复后自动回归
- 诊断端点新增每条会话的结构化快照与全局计数器时间窗
- 探针 PONG 响应新增服务端时间戳，客户端可测量真实 RTT
- Trojan 入站的 DNS over DoH 支持（UDP 53）保持可用

## 修复

- 修复 X 手机 app 无法加载内容的问题（部分反代出口被站点边缘规则拦截，现已自动避开）
- 修复首次访问网站或应用明显偏慢的问题（域名解析不再阻塞出站连接，全新域名首包提速约 4~8 倍）
- 修复反代入口假活时只会尝试一个入口、之后静默挂起的问题（现已链式换入口，全部失败时明确报错）
- 修复错误关闭的原因会挤出诊断信息的问题（错误关闭现在保留出口信息，且全部进诊断端点）
- 修复 XHTTP 协议响应头晚于出站建立导致客户端死锁的问题
- 修复 XHTTP 认证失败会回显协议关键字的问题（现与其它入站一致走中性页）
- 修复未持凭据者可占用服务器内存的问题（认证前的请求体有硬上限）
- 修复客户端以 Blob 形态发送数据时整条隧道静默失效的问题
- 修复客户端开启多路复用或 flow 时无提示挂起的问题（现明确拒绝并说明原因）
- 修复 DNS 代理会把 IPv6 地址返回给客户端的问题（现自动过滤，避免连不上的地址）
- 修复诊断端点被未鉴权请求全局锁死的问题（限流改为按来源 IP 分桶）
- 修复测速端点被滥用绕过流量预算的问题（WebSocket 探测连接纳入预算窗口）

## 优化

- 出站拨号改为滑动窗口：任一候选失败立即补发下一个，不再被批内慢候选拖住
- DNS 解析主路径跳过优选库查询并设独立短预算，全新域名首包不再陪等境外解析
- 反代入口的粘性选择考虑冷却状态，已确认失效的入口自动顺延
- 代理握手超时跟随拨号预算剩余时间，多候选不再叠加超预算的等待
- 面板「自定义反代入口池 / 固定落地 IP」只显示自己填写的条目，出厂兜底隐形生效
- 出厂兜底条目不固化进用户配置，入口失效更换时自动跟随内核更新
- 出站协议响应头固定为空扩展，不再回显客户端参数（与官方服务端行为一致）
- DNS 代理响应自动过滤 IPv6 记录，避免客户端拿到连不上的地址
