三步上手

1. 打开 节点来源，按需勾选「官方优选 IP / 优选域名 / 手动优选 IP」——都不勾也会自动给 20+10；
2. 复制 订阅 页里的地址导入客户端（Clash / Sing-box / v2ray）；
3. 想要更快的节点？在 节点来源 底部跑一次本地真连接优选，结果会进入「手动优选 IP」。

选择节点来源

三种来源可自由组合，按 官方优选 IP → 优选域名 → 手动优选 IP 的顺序合并去重。 如果三个都不勾选，会自动生成 20 个官方优选 IP + 10 个优选域名，保证订阅不会为空。

从 Cloudflare 官方网段随机生成的 IP。Cloudflare 的 IP 是全球 anycast，静态表必然过期，所以按需随机取。
