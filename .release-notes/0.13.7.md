# CFPilot v0.13.7

## 新增

- 桌面版部署页「运行状态」卡片：本地服务与环境提示、部署实例与内核版本左右分栏
- 桌面版部署页新增本地部署留档，常态下不调用令牌即可显示内核版本与部署实例信息
- 面板凭据改为弹窗展示，敏感信息不再常驻页面
- 控制面面板「出站与高级」各字段的格式与作用说明恢复
- 节点来源：自定义域名库与内置随机域名互补下发，重复自动合并

## 优化

- 内核版本等长文本改为横向滚动，按超出量精确位移，不再滚到一半消失
- 检测到可升级时，「可升级」以警示色加粗高亮
- 部署实例信息精简为「账号 · 控制面 / 数据面」
- 控制面面板「出站与高级」排版收紧，说明行更紧凑
- 桌面版凭据页移除重复的「目标账号」栏，说明并入 KV 提示

## 修复

- 点击「检查部署状态」后内核版本信息不刷新，被本地留档覆盖
- 部署实例信息只显示账号，缺少控制面与数据面名称
- 运行状态长文本溢出时显示不全
- 优选结果表缺少质量报告入口
- 报告中的 TCP 耗时与测速峰值恒为未执行
- 稳定性 P95 与抖动无法计算
- 报告耗时缺少单位，报告排版纵向占用过大
