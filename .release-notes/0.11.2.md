## 新增

- **链式代理（自建落地节点）**：桌面版「部署」页新增卡片，可一键在自有 VPS 上部署带口令的 SOCKS5 落地节点；链路为 客户端 → Worker（前置）→ VPS（落地）→ 目标站，解决 Worker 出口是机房 IP 导致的风控问题
- 命令行新增 `cfpilot vps`，支持 `--ssh root@IP`（直接远程执行）、`--print`（只输出脚本）、`--out`（落地到指定路径）
- **订阅链接签名**：面板「订阅中心 → 订阅链接安全」可签发 HMAC 令牌，支持一键轮换让旧链接立即失效；默认仍是经典链接，切换走「签发 → 逐台验证 → 再切模式」三步
- **出口体检**（实验，默认关）：数据面新增 `/__unlock_probe`，按机房去重探测站点可达性并缓存 10 分钟；命令行 `--unlock` 会输出各机房结果
- **UDP/53 → DoH**（实验，默认关）：客户端把 DNS 走代理时不再被断开，修复「能连上、能测速、但网页打不开」
- 机房显示城市名（`HKG` → `香港 HKG`），面板表格、订阅节点名、命令行对照行三处一致

## 修复

- sing-box 订阅的 `dns.rules` 引用了空的 `rule_set`，导致国内域名也走境外 DoH
- sing-box 的 `route` 只硬编码了 `.cn` 直连；现在补上内网地址与国内常用域名后缀（内联清单，不依赖远程规则集下载）
- 扫描备注解析固定取最后两段数字，备注末尾多一段文字就会把延迟/速度读丢；改为从尾部找最后两个连续数字
- 桌面版「部署」页的链式代理在 ssh 无密钥时不再静默挂住，而是立刻失败并提示改用「复制命令」

## 优化

- 内核体积预算由 80KB 调整为 96KB：80KB 是早期自定的数，而静态脱敏会把 260 个含中文的字面量整段 base64（体积 ×1.33），80KB 时控制面只剩 26 字节余量
- Release Desktop 工作流改为完整检出（`fetch-depth: 0`），修好 tag 注释与自动变更列表两个回退来源
