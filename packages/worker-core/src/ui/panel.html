本地真连接优选（True-Connect Scanner）

在本机以数据面专属域名作 TLS SNI 与 HTTP Host，实测 TCP / TLS / WebSocket 101 握手， 把高速 IP 回填到「本地真连接池」。 优选由 CLI 完成，本页只给出用法说明。 

npm i -g cfpilot
cfpilot scan --host <数据面域名> --panel <控制面域名>

免安装：把 npm i -g cfpilot 换成 npx -y cfpilot@latest scan … 即可。 需要 Node.js 18+；扫描期间请关闭本机代理的 TUN 模式与系统代理，确保测的是真实直连质量。 

cfpilot scan --help

常用：--top 保留节点数、--sample 抽样规模、 --countries 地区过滤、--no-callback 只输出不回填。

「仅代理」保证出口 IP 与配置一致（直连会暴露 Cloudflare 原生出口）。 代理全部失败时会尝试反代入口池（同样是第三方出口），仍失败则报错。 四种模式改变的是候选优先级与回退顺序，不是简单开关：代理与直连不会混进同一竞速池， 因此不会出现「直连先成功、出口 IP 与预期不符」。

IPv6 支持边界：入站可解析 IPv6 目标，SOCKS5 与 HTTP CONNECT 上游也可写 IPv6 地址； 但 Worker 本身不支持直接连接 IPv6 目标出站，此类目标需经代理落地或 NAT64 转换。
