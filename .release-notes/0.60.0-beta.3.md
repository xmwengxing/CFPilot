## 新增

- 桌面版凭据页新增 **「面板请求代理」**：优选回填与面板登录访问控制面域名时使用，支持 http / https / socks5；留空则按环境变量 → 系统代理 → 直连自动选择，并显示当前实际生效的来源
- 组网版新增 **路由器端口映射**：启动时向路由器申请把本机 UDP 监听端口映射到公网，依次尝试 NAT-PMP、PCP、UPnP，续约由后台自动完成；默认关闭，失败不影响组网
- 组网新增 **多跳转发**：两端无法直连时可由其它在线节点中转，拓扑页会显示实际经过的节点
- 组网握手新增密钥确认：连接建立前先核对双方密钥是否一致，不再出现「连上又立刻断开、反复重连」

## 修复

- Windows 版被安全软件判为木马并直接隔离的问题：面板窗口的加载组件此前从内存执行，现在改为从本地文件加载，官方组件随包附带
- 修复勾选 ECH 后订阅节点全部失效的问题（ECH 配置查询失败时不再拒绝连接）
- 修复 macOS 12 上打开应用提示「需要 macOS 13 或更高版本」的问题，最低支持回到 macOS 12
- 修复 macOS 版应用内更新只替换可执行文件、更新后应用信息与资源仍是旧版的问题，改为下载安装包整包替换并在失败时回滚
- 修复绑定自定义域名后回填仍访问 `*.pages.dev` 导致 TLS 握手超时的问题，回填与面板登录优先使用控制面项目实际绑定的自定义域名
- 修复部分网络下 `*.pages.dev` 直连被阻断时回填必定失败的问题，直连不通会自动改用本机代理重试
- 修复自动识别域名时「明明绑了域名却识别成 pages.dev」没有任何说明的问题，现在会说明项目读取失败或控制面尚未绑定域名
- 修复关闭双栈监听后仍以 IPv6 监听的问题；只有 IPv4 的网络里，组网状态也不会再显示成 IPv6
- 修复组网打洞的地址族选择：只向本机网卡能发出的地址族发起探测，不再出现「状态显示打洞中、实际没有探测发出」

## 优化

- 内置反代入口每日自动体检更新，已部署的实例无需重新部署即可拿到新的可用入口
- 内核产物进一步脱敏：反代清单源、DoH 端点这类带路径的完整地址不再以明文出现
- 组网传输改为批量收发，并按链路给出收发与丢弃分类统计，卡顿与丢包更容易定位
- 面板里「自定义反代入口池」「固定落地 IP」「单连接流量上限」「无响应换入口上限」等说明文字更简短，并补全适用条件
- Windows 版新增 `+loader.zip`（免安装，解压即用），与安装向导版一样附带官方面板加载组件
