# CFPilot v0.12.0

## 新增

- **桌面版优选结果历史列表**：每次优选成功（本地真连接优选 / 一键优选）自动留底，保留最近 30 次；展开任意一次结果可勾选任意 IP ——「复制选中 IP」生成 `IP:Port#机房` 列表直接粘回面板，「复测选中」按 TCP → TLS 握手 → WebSocket 101 分层校验（勾选「带测速」可同时重测下行），能看出是哪一层挂了；复测使用该次会话保存的域名与 WS 路径（不受当前表单影响），结论自动写回历史条目
- **单 IP 独立诊断**：命令行新增 `cfpilot test --host <域名> --ip <IP>`，按 TCP → TLS → WS 101 → PONG → 测速 → 真实隧道六阶段逐级给结论，一眼看出卡在哪一层
- **配置备份与迁移**：面板「高级」新增导入导出，导出走**白名单**（凭据、入站路径、自定义域名、带口令的落地代理一律不导出），导入先展示与当前配置的差异再写入
- **后端配置强校验**：路径、域名、代理条目、数量上限、端口、UUID 等非法配置由后端直接拒绝并给中文原因，不再依赖前端单点校验
- **兼容性矩阵**：README 精简表 + `docs/COMPATIBILITY.md` 详细版
- **桌面版运行状态卡片**：部署页显示本地服务、部署实例、内核版本与环境提示，附控制台直达入口

## 修复

- XHTTP 收到 UDP 命令时未取消剩余请求体，连接会挂着不释放：改为经内部流转发取消（不能直接 `body.cancel()` —— 原始流已被读取器锁定），并明确返回 400
- 探测 WebSocket 无空闲超时，异常客户端可长期占用连接：accept 后 5 秒空闲自动关闭，收到非预期消息立即结束，正常关闭/出错时清定时器

## 优化

- 「开始优选」上方的流程说明重写为完整四阶段描述（TCP 初筛 → TLS 筛选 → 两层校验 → 稳态测速），默认折叠为「优选IP流程说明」，需要时再展开，不再占用页面空间
- 扫描报告可复现：JSON 报告补齐采样参数、随机种子、运行环境与**各阶段失败原因分布**（「101 失败 812 个」分类后能看出是 403 多还是超时多）
- 诊断接口的 `?token=` 查询参数标记废弃：令牌走 URL 会进浏览器历史、Referer 与边缘日志，统一改用请求头传递
