# CFPilot v0.13.0

## 新增

- 数据面部署模式可选 **Pages（默认）/ Workers**，在部署卡片内直接切换
- Workers 模式部署完成后，提示自定义域名的绑定位置，以及回面板填写「数据面域名」的路径
- 切换部署模式时自动清理旧数据面（Pages 项目或 Worker），并提示重新绑定自定义域名
- 手动部署文档新增 Workers 流程，仓库根目录提供可直接粘贴的 `_worker.js`

## 修复

- 内核版本比对错误，导致状态卡永远显示「可更新」，且把线上内核显示成语义版本而非构建号
- 切换部署模式时被「同版本跳过」拦截，模式实际没有生效
- 首次部署 Workers 模式时控制面缺少数据面域名，订阅里的节点没有地址

## 优化

- 部署状态卡拆成「已部署 / 最新发布 / 本程序内置」三行，三个版本各自对应一个来源
- Workers 模式所需 API 权限减少到四项，不再需要 Workers Routes 与 DNS
- 「已部署」内核版本优先采用数据面实际运行的版本，不再只依赖部署记录
