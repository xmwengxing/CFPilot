# CFPilot 0.9.4

本轮四件事：**内置优选域名库按实测重换**、**修好订阅卡片名带引号/斜杠**、**一个链接通吃所有客户端**、**面板亮色主题恢复**。

## 修复

- **面板右上角色盘点了不切亮色主题（只影响 Pages 面板，桌面版正常）**
  根因在构建脚本 `scripts/gen-panel.mjs`：它把所有内联 `<script>` 段都替换成**同一个**占位符，而 `String.replace(字符串, …)` 只替换第一个 ——
  于是**前一段代码整段丢失**（正是主题切换那段），第二个占位符原样留在 HTML 里变成一个 SyntaxError 的死 `<script>`。
  panel.html 里现在有两段 script（主题 + 主应用），所以只有面板坏、桌面版（`packages/ui` 不做这个提取）正常。
  已改为**逐段提取、逐段压缩、逐段回填**，并加了构建自检（占位符不许残留）。
  真机浏览器（headless Chrome）验证：点击后 `body.light` 生效、背景从 `rgb(9,13,22)` 变 `rgb(242,245,250)`、偏好写入 localStorage。

- **Clash / Mihomo 订阅卡片名出现引号和斜杠**（如 `\"CFPilot\`）
  响应头 `Content-Disposition: inline; filename="CFPilot"` 里的**引号被部分客户端原样当成名字**；
  名称里若再含 `/`、`|`，还会被二次截断。现在：
  - 纯 ASCII 名称**不带引号**下发：`filename=CFPilot`；
  - 额外给一份 RFC 5987 的 `filename*=UTF-8''…`（中文名也能正确落名）；
  - 名称清洗扩大到剔除 `" ' \` / | ; : & ? # %` 及控制字符；
  - `Profile-Title` 在非 ASCII 时按 RFC 2047 编码；
  - `Subscription-Userinfo` 从空值改成显式的 `upload=0; download=0; total=0; expire=0`（空值会让部分客户端弹解析警告）。

- **构建顺序隐患**：`workspaces` 顺序原来是 cli → worker-core，导致 `npm run build` 里 CLI 先同步了**上一版**内核产物，
  每次都得手动再跑一次 `npm run build -w cfpilot`。已把 worker-core 排到前面，一次构建即可一致（CI 的资产一致性校验也受益）。

## 新增

- **自适应订阅地址（一个链接通吃）**：`https://<控制面>/sub/<UUID>` 不带任何参数，
  客户端按自己的 User-Agent 自动拿到对应格式 ——
  v2rayN / v2rayNG / Shadowrocket / NekoBox → Base64 分享链接；
  Clash / Mihomo / Clash Verge → YAML；Sing-box → JSON；识别不出时回落 Base64。
  已放到面板**运行概览**页首屏（带「复制订阅链接」按钮），打开面板就能复制。
  真机验证：同一链接在三种 UA 下分别返回 `text/plain` / `text/yaml` / `application/json`。

## 优化

- **内置优选域名库按 2026-10-28 真机实测重换**：
  旧表 21 个域名里 **14 个已经废弃**（DNS 不解析、解析到 `127.0.0.1`、或根本不再指向 Cloudflare），
  订阅里半个节点是废域名，客户端就表现为「优选出来的 IP 全部 -1」。
  新的 28 个域名全部通过「解析到 CF 网段 + 以数据面域名做 SNI 的 WebSocket 升级返回 101」实测（每域名 2 轮 2/2）：
  - 商业级托管域名 18 个：`www.visa.com` / `www.visa.com.sg` / `www.visa.com.hk` / `www.visa.com.tw` / `www.visa.co.jp` /
    `www.visakorea.com` / `time.is` / `icook.hk` / `icook.tw` / `ip.sb` / `japan.com` / `singapore.com` /
    `malaysia.com` / `skk.moe` / `www.digitalocean.com` / `www.udemy.com` / `www.garmin.com` / `www.wto.org` / `www.speedtest.net`
  - 仍在维护的社区优选池 9 个：`cf.090227.xyz` / `node.cf.090227.xyz` / `cloudflare.182682.xyz` / `cdn.cloudflare.182682.xyz` /
    `bestcf.top` / `cdn.2020111.xyz` / `cf.0sm.com` / `cloudflare-ip.mofashi.ltd` / `xn--b6gac.eu.org`
  被删掉的 14 个（含原因）写在 `src/data/pools.ts` 的注释里，并加了回归测试钉住「死域名不许回来」。

## 升级提示

本版本内核有改动，需要**重新部署内核**才能生效：

```bash
npx -y cfpilot@latest deploy
```

已部署实例直接原地更新即可（沿用原 UUID / WS 路径，客户端订阅地址不变）。
⚠️ 旧的订阅卡片名是客户端**导入时**记下来的，更新订阅后如果名字还带引号，删掉卡片重新添加一次即可。
