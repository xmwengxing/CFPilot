## 新增

- 新增更安全的本地扫描桥接服务鉴权，降低网页跨域调用本机扫描能力的风险
- 新增远程内核官方摘要清单校验，拒绝来源异常或版本路径异常的内核产物
- 新增远程优选池响应体大小限制，避免异常数据源占满运行内存
- 新增 DoH 解析并发去重与空结果短缓存，减少重复解析请求
- 新增 WebSocket 与 XHTTP 暂存数据的实例级内存预算保护
- 新增长期扫描令牌环境变量回退校验

## 修复

- 修复未授权注销请求可大量消耗 KV 删除配额的问题
- 修复 XHTTP 分包首块泵出后剩余数据不计入内存预算的问题
- 修复 XHTTP 长时间活跃隧道被错误回收的问题
- 修复配置路径与已有入站路径冲突时可能导致入站不可用的问题
- 修复非法代理模式可能绕过指定代理直连的问题
- 修复订阅密钥轮换后部分边缘仍使用旧密钥的问题
- 修复 KV 陈旧读期间面板路径与密码可能被重复生成覆盖的问题
- 修复 Clash 订阅中的指纹字段与自定义路由组可能破坏 YAML 结构的问题
- 修复环境变量配置的 WebSocket 路径缺少前导斜杠时无法匹配的问题
- 修复部署失败或未确认成功时仍继续部署、写入成功清单或显示成功的问题
- 修复远程内核缓存摘要可能被本地篡改后继续信任的问题
- 修复桌面版启动令牌可重复使用并写入日志的问题
- 修复桌面版测速过早结束导致高速链路结果偏低的问题
- 修复扫描桥接回填请求自动跟随重定向并泄露响应体的问题
- 修复 Go 版与 CLI 版远程内核版本校验规则不一致的问题

## 优化

- 优化 HTTPS 代理的 SNI 传递，提升按域名路由代理的连接成功率
- 优化拨号失败后的连接回收，减少失败转移等待时间
- 优化 XHTTP 暂存额度按分包逐块回收，降低慢速目标造成的内存峰值
- 优化 CLI 与桌面版测速口径，统一预热期、稳态吞吐和持续测量行为
- 优化测速提前结束时的定时器与连接清理，避免残留连接干扰下一候选
- 优化会话缓存与 KV 传播窗口处理，减少跨边缘登录和订阅链接抖动
- 优化配置校验与订阅生成的输入安全边界
- 优化远程内核资产下载地址，镜像仅用于发现版本或传输产物
- 优化桌面版部署取消、代理探测和凭据写入的资源管理
- 优化控制面产物体积，保持在平台预算范围内
