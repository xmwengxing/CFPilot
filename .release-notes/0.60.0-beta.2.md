## 新增

- **macOS 版发布**：桌面版新增 macOS 原生应用窗口（WebKit 承载，与 Windows / Linux 版同一套界面与托盘行为），提供 Intel 与 Apple Silicon 通用的 `.dmg` 安装包
- 桌面版定时优选任务新增 **「竞速回填」** 开关：每轮先把面板本地真连接池里已有的 IP 拉进候选队列，与新采样的 IP 一起做真连接校验与下行测速，再把最快的前 N 条（N = 任务的保留条数）覆盖写回面板池

## 修复

- 修复部分 sing-box 内核客户端订阅节点全部无法连接的问题，表现为延迟测试正常但 URL Test 全部超时
- 修复凭据页把同一账号下其它项目使用的 KV 空间显示为空、可能被误选并覆盖的问题，现在会标记为已被其他项目占用并禁止选择
- 修复部署更新提示在更新完成后仍反复出现的问题
- 修复安卓版优选页点击「自动识别」后长时间没有任何反馈的问题，现在点击即时响应并在输入框下方直接显示结果或失败原因
- 修复优选页把「探测传输」选为 XHTTP 时结果恒为空（一个 IP 都选不出来）的问题，并在校验全部失败时直接说明该检查哪一项
- 修复优选页把「测速」选为「关」时界面显示已关闭、实际仍在测速的问题
- 修复 macOS 版应用内更新只替换应用内的可执行文件、更新后应用信息与资源仍是旧版的问题，改为下载安装包整包替换并在失败时回滚

## 优化

- 桌面版任务清单为开启了「竞速回填」的任务显示标记，悬停可看到它会先读面板池、跑完再覆盖回填
- macOS 版首次打开需在「系统设置 → 隐私与安全性」中放行一次，之后与应用内更新均不再提示
