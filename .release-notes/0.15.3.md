## 新增

- 反代优选：逐个验证反代 IP 能否把域名转发到自己的数据面，结果可直接写入面板的 ProxyIP 池
- 优选页新增二级页签：入口优选 / 反代优选，两个方向共用数据面域名与 WS 路径
- 候选来源：支持粘贴、导入 csv/txt、从链接导入，并实时显示「已识别多少个 IP」
- 内置 Proxy IP 源：手上没有 IP 清单时也能直接跑反代优选（随版本发布，用户不可修改）

## 优化

- 内置反代入口换成实测过的固定 IP：同一客户端出口更稳定，不再频繁变化
- 内置反代入口不再每次出站都做域名解析，可同时尝试的入口更多
- 订阅节点名不再重复显示机房，数字尾巴只保留速度
- 优选历史支持多个批次同时展开、跨批次勾选，复制与复测都可跨批次

## 修复

- 桌面版换新版本后，凭据页的账户可能显示为空、提示重新添加令牌（凭据其实没丢，刷新即可恢复）；已改为界面资源不缓存，不会再出现
- 「候选来源」里「默认」的说明写错成「反代＝需用自定义列表」，实际默认直接使用内置 Proxy IP 源
- 反代优选遇到个别候选连接异常会中断整轮体检
- 优选命令读取带备注的 CSV 时整行可能被跳过
- 桌面版导入带序号的 CSV 会解析出 0 个候选
- 优选结束后总进度条停留在「处理中 · 总进度 1%」
- 优选历史复制 IPv6 地址时缺方括号、缺数字尾巴
- 优选结果的「质量报告」被列宽挤扁，改为展开独立报告
- 「复测带测速」默认不勾选
