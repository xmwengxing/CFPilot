# CFPilot 0.9.3

本轮是一次**风控与配额加固**：把控制面也从「明文裸奔」拉进静态脱敏范围，修掉一个会**耗尽 KV 免费写配额**的现网 bug，并补齐订阅侧两个真实功能缺陷。

## 修复

- **KV 写配额被写光（会直接让面板瘫掉）**：注入 `PANEL_PASSWORD` 时，每次鉴权引导（60 秒缓存过期 / 每个边缘 isolate 冷启动）都会重写 `ADMIN_PW_HASH` 并 `delete` 明文副本 —— 免费版每天只有 1000 次写/删除，配额耗尽后「保存配置 / 回填优选 IP」全部 500。改为**先比对再写**：密码没变时稳态 **0 次写**。
- **面板「自定义域名库」对订阅完全不生效**：`/sub/*` 调用优选引擎时漏传 `domainPool` 与 `budget` —— 表现为「面板预览里有自定义域名、客户端拉订阅却没有」，且订阅没有 CPU 预算保护。
- **非 WebSocket 访问代理路径返回明文 JSON**（`{"ok":false,"error":"该路径需要 WebSocket 升级"}`）：源码脱敏管不到运行期响应体，这是最直接的代理指纹。改为伪装成普通静态站。
- **残留中文诊断明文**：`出站被 Cloudflare 拒绝（…）`、`出站超时（…）`、`[自研数据面] …` 等未被词表覆盖的文案会留在产物里，并会通过 close reason 回显给客户端。改为「含汉字即整类编码」。
- **出站并发超过平台上限**：Workers 单请求同时出站 TCP 上限 6 条，原实现反代第一批 8 个 + 直连/优选同池竞速会瞬间发 10+ 条，超限的 `connect()` 直接抛错（候选被浪费、诊断混入假失败）。改为窗口化分批。
- 探针 HTTP 代理默认 UA 与外部优选池拉取 UA 换成通用浏览器 UA（不再把项目特征写进每一次外部请求）。

## 新增

- **控制面静态脱敏（literals 模式）**：`control.js` 里的 21 个第三方优选域名、`type: vless` 订阅模板、项目 UA 等特征全部编码。控制面离 80KB 预算只剩约 10KB，所以只改字符串字面量、不改属性名。
- **`scripts/check-kernel-desensitize.mjs`**：从**源码**反查产物 —— 33 个第三方域名一个都不许明文出现、面板 HTML 的 gzip 载荷必须完好、两个产物都必须带缓存版 `__sfx` 解码器并在 80KB 内。已挂进 `npm run verify`。
- `/__diag` 诊断端点需要 token（`?token=` 或 `x-cfpilot-token`，值为 uuid 或 uuid 前 8 位）—— 它会把用户最近访问的目标域名与失败原因吐出去。
- 远程优选池（ADDAPI / ADDCSV）增加 **120 秒内存缓存**：订阅被客户端反复重拉时不再重复打外部 URL；面板预览自动绕过缓存，保证「点一下就看到最新」。
- 控制面对明显静态路径（`/`、带扩展名）不再触发鉴权引导，省掉无意义的 KV 读。

## 优化

- `__sfx` 解码器加**结果缓存**：每个 base64 字面量整个实例生命周期只解码一次（原先每请求热路径会重复 `new TextDecoder()` 几十次）。
- 编码判据从「关键词枚举」扩到**四类整类覆盖**：中文、域名形态、`key: value` 配置形态、敏感词表 —— 不再靠人肉补词。
- 优选抽样随机数：`sampleFromCidrs` 最坏 4800 次加密级随机调用 → 改用 `Math.random()`（凭据生成仍走 crypto，未动）。
- 面板 SSE 轮询 3 秒 → 15 秒（面板开着时 KV 读 1200 次/小时 → 240 次/小时）。

## 验证

- 单元测试 **504 passed**（上版 469，本轮 +35）。
- 类型检查 / 构建 / 8 个 check 脚本 / Go `test`+`vet`+`gofmt` 全绿。
- **真机验证**（在独立新账号上新建一对临时实例，验完即删）：
  - 连打 40 次面板请求后 `ADMIN_PW_HASH` 的盐**一字未变**（= 0 次 KV 写）；
  - 写入自定义域名 `verify-custom-domain.example.com` 后，Clash 订阅里立即出现该节点（修复前不可能）；
  - 非 WS 访问代理路径 → `200 text/html` 破冰欢迎页（原为 400 JSON）；
  - `/__edge_probe?bytes=1024` → 1024 字节 + `x-probe-bytes`；WS 101 + `{"pong":true,"colo":"LAX"}`；
  - CLI 端到端扫描 240 候选 → 8 个节点（全 LAX）→ 成功回填面板。

## 升级提示

本版本改动**全部在内核**，需要**重新部署内核**才生效：

```bash
npx -y cfpilot@latest deploy
```

已部署实例直接原地更新即可（不需要新建 KV / 项目）。
