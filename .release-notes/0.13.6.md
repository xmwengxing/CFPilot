# CFPilot v0.13.6

## 新增

- 优选结果 IP 质量报告：桌面版历史里每个 IP 都能展开详细报告，包含连接、协议、性能、出口与历史稳定性
- 报告支持字段悬浮说明：每项指标都能看到定义、数据来源、影响与参考值
- 报告的耗时与速度按阈值着色，TCP 耗时、峰值速度与稳定性 P95 开始提供真实取值
- 出口识别（实验性）：可用自有识别服务查看指定传输路径的实际出口地址
- 网站兼容性检测（实验性）：可对用户指定的站点做低频真实访问检测
- 自适应网段权重（实验性）：按本机网络档案的历史表现调整采样权重，并保留探索预算
- 优选总进度条：一条进度条贯穿全程，按阶段显示总体进度

## 优化

- 优选结果区布局调整：总进度条移到结果框下方，按钮行只显示当前阶段的数字进度
- 「两个按钮的区别」说明改为默认折叠，不再占用优选结果区域
- 报告排版改为左右分栏，中间带分隔线，纵向占用明显减少
- 优选结果表中的 TCP 耗时列显示真实建连耗时，握手延迟改为悬浮提示
- 优选历史支持保存有界复测样本，历史会话按版本化格式存储

## 修复

- 质量报告的「查看」按钮因缺少会话标识而无法点击
- 优选结果表没有质量报告入口，只有历史里能看到
- 报告中的 TCP 耗时与测速峰值恒为未执行，实际数据没有随优选结果一起保存
- 稳定性 P95 与抖动无法计算，样本不足时也无法给出明确说明
- 报告耗时缺少单位，慢速与快速节点难以区分
- 报告排版纵向过长，字段之间缺少分隔
