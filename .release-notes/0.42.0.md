## 新增

- 出厂内置 x.com 与 cloudflare.com 的固定落地、固定反代入口：零配置即可稳定访问这两类站点
- 自定义固定落地映射按域名合并：自己配置的条目优先生效，出厂优化不会被顶掉
- 托盘气泡提示有新内核可更新：只更新内核、不发新版本时也能第一时间知道
- 检查部署状态可感知内核更新：明确显示「可升级」或「已是官方最新」，并写入日志
- 入口优选结果按下行速度自动排序，表头可点击切换排序，优选历史同样支持
- 反代优选结果按保留条数精简展示，每个入选 IP 显示对各个校验网址的转发延迟

## 修复

- 修复检查部署状态感知不到内核更新的问题
- 修复内核已是最新时按钮仍提示更新、点击反而降级的问题
- 修复托盘不提示内核更新的问题

## 优化

- 面板「链式代理 / 自定义反代入口池 / 固定落地 IP」三个填写框并列一行，说明精简为一条
- 反代优选逐个网址实测并记录耗时，方便对比不同候选对各站点的转发快慢
