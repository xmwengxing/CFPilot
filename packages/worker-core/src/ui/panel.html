#来源地址机房

入站参数

443 被针对性干扰时，勾上备用端口即可（Cloudflare 的 TLS 端口都直通 Worker）。
手动优选 IP 里显式写了 IP:端口 的条目保持原端口，不参与端口乘法。

订阅里每个节点会按这里勾选的形态各生成一份。
· VLESS + WebSocket：兼容性最好，Clash Verge / mihomo / v2rayN 都支持。
· VLESS + XHTTP：仅 Xray 内核支持；Clash / mihomo / sing-box 不认这个传输。
· Trojan：需要数据面开启 Trojan 入站（默认已开启）。
没勾选的形态**不会**出现在订阅里，节点数也不会被乘三。
对应 XHTTP 入站没开启时，XHTTP 形态会自动跳过。

出站与抗封锁

目标站点解析到 Cloudflare 网段时，Worker 不能连回 Cloudflare 自家入口， 必须经第三方反代按 SNI 转发。内置表依赖社区第三方服务；填入自己的入口可完全不依赖它。
开启后，Worker 会用 DoH 解析目标域名取得可用落地 IP（TXT 优选库优先，回退 A/AAAA）。 Worker 不能连回 Cloudflare 自家 Anycast 入口，解析到的 Cloudflare 网段 IP 会被自动降权。

ECH 让客户端把 TLS ClientHello 里的真实域名加密，隐藏你访问的是哪个域名。 这是客户端侧的能力：内核只负责把参数写进订阅，由支持 ECH 的客户端 （mihomo / sing-box 1.13+ / v2rayN 等）实际执行。客户端不支持时该参数会被忽略。
