# CFPilot 0.9.5

本轮修掉两个**真机必现**的缺陷：**Trojan 节点全部 -1** 与 **运行概览两张卡片看起来是硬编码**；另外把 XHTTP 的默认值与真实可用性讲清楚。

## 修复

### Trojan 节点全部 -1（协议级 bug）

数据面对 **Trojan 客户端也回了 VLESS 的协议响应头**（`00 00`）。VLESS 有这个响应头，**Trojan 协议没有** ——
认证通过后服务端应当直接透明转发，客户端读到的第一个字节就是目标站的数据。

真机抓到的 Trojan 下行开头：

```
0000 485454502f312e312034303320466f7262696464656e...   ==  "\0\0HTTP/1.1 403 Forbidden"
```

客户端把这 2 个 NUL 当成隧道数据 → TLS 记录头错位 → 握手失败 → **全部 -1**。
修复后同一条链路、同一握手报文，下行开头变成 `485454502f31...`（`HTTP/1.1 301 Moved P...`，241 字节真实响应）。

VLESS 的响应头行为保持不变（回归测试钉住），并新增 3 个用例覆盖「trojan 不发头 / vless 仍发头 / 口令错时不发数据」。

### 运行概览两张卡片像硬编码

- **系统内核版本**：`/api/v1/status` 里 `version` **写死成 `'0.1.0'`** —— 面板永远显示 0.1.0。
  现在返回两个真实值：`version`（`<git短hash>-<源码哈希>`）与 `pkgVersion`（`0.9.5` 这类语义版本，构建期注入），
  面板显示成 `0.9.5 · <hash>`。
- **当前接入边缘机房**：值本身是真的（`request.cf.colo`），但面板**只在登录后读一次**。
  现在切回「运行概览」会自动重新读取，并在卡片下方显示「以上数据读取于 HH:MM:SS」。
- `/__cfp_version` 同时增加 `version` 字段（部署向导仍读 `build`）。

## 变更

- **XHTTP 服务端默认开启**（原来部署固定写 `ENABLE_XHTTP=false`，面板勾了也不生效）。
  现在 CLI 与桌面版部署都默认 `true`，之后由面板「入站配置 → 启用服务端 XHTTP 入站监听」控制
  （面板写 KV，优先级高于环境变量）。
- ⚠️ **但 XHTTP 在 Cloudflare 上实际不可用**，面板里已加显式警告：
  标准 Xray 客户端发的是 `Content-Type: application/grpc`，**Cloudflare 边缘对这个类型直接回 403**，
  请求根本到不了数据面。实测对照：

  | Content-Type | 结果 |
  |---|---|
  | `application/grpc` / `application/grpc+proto` | **403（Cloudflare 边缘拦截）** |
  | `application/grpc-web` / `application/octet-stream` / `text/plain` / 无 | 400（到达 Worker，说明路由本身没问题） |

  所以勾选 XHTTP 生成的节点在标准客户端里必然 -1；只有能把 Content-Type 改成
  `application/octet-stream` 之类（并在请求体上匹配）的客户端才可能通。
  订阅里默认**不勾** XHTTP 形态，服务端开着不产生任何副作用。

## 验证

- 单元测试 **533 passed**（+9：Trojan 响应头 3 + 运行概览数据 6）。Go `test`/`vet`/`gofmt` 全绿。
- 真机（独立新实例，验完即删）：
  - Trojan → `baidu.com:80`：241 字节真实响应，开头 `HTTP/1.1 301 Moved P`，**无 `00 00`**；
  - VLESS → 同目标：仍有 `00 00` 响应头 + 数据（未回归）；
  - XHTTP：`text/plain` 等类型能到 Worker，`application/grpc` 被边缘 403（见上表）；
  - 面板：主题切换、自适应订阅地址均正常。
- 本地 workerd 也跑了同一组报文（不受外网影响）：Trojan 直接拿到 413 字节完整 HTTP 响应。

## 升级提示

内核有改动，需要重新部署：

```bash
npx -y cfpilot@latest deploy
```

更新后用 `curl https://<数据面>/__cfp_version` 确认 `build` 已变化；面板「运行概览」的内核版本也会显示新值。
Trojan 客户端更新订阅后即可使用（记得在订阅形态里勾上 Trojan + WebSocket）。
