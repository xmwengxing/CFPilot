快速配置指南

1

编排节点来源

在「节点来源」中按需启用官方 IP、优选域名或手动池。未勾选任何来源时系统将自动启用 20+10 保底策略。

2

执行本地真连接优选

在「本地优选」中以您的专属数据面域名作为 SNI 完成 WebSocket 101 实测，筛选本机直连质量最佳的边缘 IP。

3

导入客户端订阅

前往「订阅中心」复制自适应链接（支持 V2Ray / Clash Mihomo / Sing-box），粘贴至客户端即可使用。
