## 新增

- 面板新增「固定落地 IP」配置：按域名写死出站落地地址，跳过 DNS 轮询
- 固定反代入口：为 Cloudflare 网段站点指定实测最快的反代入口，跳过粘性轮换
- 桌面版反代优选新增「校验网址」终检：实测候选能否转发到 Cloudflare 网段站点，自动剔除假入口
- CLI 反代优选同步支持校验网址终检（--verify-hosts）
- 内核支持独立于工具版本的热更新：部署前自动检查并拉取最新内核
- 桌面版说明页「检查更新」移至最上方，检查后显示发布说明

## 修复

- 修复部分网站刷新时好时坏的问题（落地节点在多家 CDN 间漂移）
- 修复 Cloudflare 网段站点访问非常慢的问题
- 修复部署进行中仍可重复点击部署按钮的问题
- 修复未选择账户时部署页缺少提示、部署出错难以定位原因的问题
- 修复面板「固定落地 IP」输入框保存无效的问题
- 修复反代入口只使用少量候选、表头失效后无备选可用的问题
- 修复出站无数据时重拨入口过少、可能在失效入口上原地重试的问题

## 优化

- 域名解析聚合多家 DoH 结果，混合 CDN 时优先使用明确的落地 IP
- 反代入口按目标域名稳定选择，同一会话出口不再漂移
- 反代入口连接超时缩短，减少失效入口的等待时间
- 质量报告「场景适配」不再重复显示，纯净度评分按分值颜色高亮
