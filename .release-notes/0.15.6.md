## 新增

- 面板新增「放宽无响应自动重拨」开关：默认只在「直连出口 + 443/80 端口 + 零下行」时自动切到内置反代；开启后取消通道与端口限制，界面里写明可能导致重复请求、绕过指定出口
- 零字节 WebSocket 会话增加独立首包超时（8 秒后 close 1008），与协议头解析超时分层，不影响 SSH / 远程桌面等正常长连接
- `/__diag` 增加出站诊断计数与最近路由记录；正常结束的 close reason 带上实际出口（`via` / `endpoint`），可据此判断目标是否经反代转发
- 新增可重复执行的数据块基准脚本，统计下行帧大小分布与 16 / 32 / 64 KB 上行分帧耗时；另附能力探测脚本

## 优化

- 竞速落败连接改用底层 `socket.close()` 整条关闭，立即释放「单请求 6 条出站连接」槽位
- 无下行自动重拨加护栏：已配置落地代理 / ProxyIP 或访问非 443/80 端口时不擅自换出口，改为明确关闭并写入分级诊断
- 上游秒级 EOF/Reset 且零下行时立即触发反代重拨；已经收到过任何响应则绝不重放，避免同一请求被重复执行
- 下行转发改用不依赖运行时属性的主动让步节流器，减少对上游预读节奏的打扰
- UUID 字节与 Trojan SHA-224 摘要按配置键缓存；CF 网段判定表在模块初始化时预编译为整数掩码
- UDP-DNS 由串行 Promise 链改为有界并发（≤ 4）加有界等待队列（≤ 32），消除队头阻塞同时保留限流语义
- DoH 解析缓存加入过期清理、容量上限与近似 LRU；中继异常按「读上游 / 写目标」分类上报
- HTTP CONNECT 改用通用浏览器 UA；XHTTP 出站补传 colo，按当前边缘机房优选邻近地区的反代入口
- 面板补充代理调度模式各取值的实际行为，以及 IPv6 支持边界（入站 / 代理上游 / Worker 直连三者分开说明）

## 修复

- 重建 CF 网段判定表，补齐 `173.245.48.0/20` 与 `190.93.240.0/20`；公共 DNS 段从降权表移出单独归类，访问这些地址不再被误导向只转发 CF 站点的反代入口
- 非官方但需降权的段单独归类，与按实测可用率筛选的优选采样池彻底分离
- `/region` 去掉免鉴权端点上的反代地区优先级字段，收敛部署特征
- ByteStream 单块 `peek()` 零拷贝；数据块基准的上行指标口径修正为「客户端入队耗时」，不再误当作网络吞吐
