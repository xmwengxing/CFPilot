# CFPilot 0.9.7

这一轮全在**桌面版**：托盘能按账号一键优选且看得见进度、凭据页按实际使用习惯重排、发布版 exe 终于带上图标。

## 新增

### 托盘「一键优选 IP」可按账号执行

- 托盘右键 → 「一键优选 IP」变成**子菜单**，每个本机已保存账号一项（`账号名 · 账号 ID 前 8 位`），当前账号带勾；
- 点哪一项，就用**那个账号自己的** Token / KV 部署清单 / 面板密码跑完整优选并回填到它自己的面板；
  查不到该账号时**直接报错，不回落到当前账号**（避免把结果回填到别人的面板）；
- 一个账号都没有时，该项**置灰**并显示「一键优选 IP（暂无账号）」。

### 进度感知（气泡放不下进度条，改用三层替代）

Windows 托盘气泡是 `Shell_NotifyIcon` + `NOTIFYICONDATAW`：结构体里只有标题 / 正文 / 图标，
**没有进度字段**；`ITaskbarList3.SetProgressValue` 只对「有可见主窗口 + AppUserModelID」的程序生效，
Win32 Toast 同样需要开始菜单快捷方式 —— 绿色单文件托盘程序都用不了。

所以改成：

- **菜单标题实时进度**：`一键优选：扫描 45/1500 · 3%`（换阶段立即刷，同阶段 300ms 节流）；
- **托盘图标 tooltip** 同步显示；
- **文本气泡**：开始 / 25% / 50% / 75% / 完成各一条（按加权整体进度判档、只升不降，不刷屏）。

运行期间账号项置灰防重复点击；结束（成功 / 失败 / panic）一定会恢复菜单状态。

## 界面

### 凭据页按实际操作顺序重排

- 「检测账号」与「检测结果」合并进**顶部同一张卡片**；
- 「删除本地账号/凭据」移到账户选择框**右侧**；
- 去掉 KV 命名空间卡片：「本次部署使用的 KV」进入账户卡片，「刷新 KV 列表」在 KV 选择框**右侧**；
- 新增「🧩 其他」卡片，收纳**面板密码**与**手动指定 KV ID**；
- 去掉「保存此选择」按钮 —— 选中账户与 KV 后**自动保存**；
- 打开页面 / 切换账户 / 点「检测账号」都会自动探测实例，并按个数给出**醒目提示**：
  - **0 个**：红框「未检查到CFPilot 实例，请到「部署」页全新部署」
  - **1 个**：自动选中并保存，绿框「已自动选中唯一的 CFPilot 实例 …，KV 已保存」
  - **多个**：红框「请在下方选择 KV」+ 列出实例名 —— 选错 KV 会让后续部署 / 优选 / 回填全部作用到别的实例上
- 删除四段冗长注释文字；顺手修掉「检测账号」重复绑定（点一次跑两遍）与 KV 列表被拉取两遍的问题。

### 优选页

- 去掉「⚡ 一键优选并回填」卡片（该能力现在只在托盘提供，界面不再重复一个按钮）。

## 修复

### 仓库下载的 exe 没有图标

根因：`.github/workflows/release-desktop.yml` **从来没安装 go-winres**，而
`scripts/build-desktop.mjs` 找不到它时只打一行 warn 就继续编译 —— 于是 CI 发布的每个 Windows exe
都「没有图标、没有版本属性」，本地因为装过 go-winres 完全正常，CI 日志里也只留下一句
`⚠ 未找到 go-winres，exe 将没有图标与版本属性`。

现在：

- 脚本改成三层策略：本机 go-winres → 回退 `go run github.com/tc-hib/go-winres@v0.3.3`（版本 pin 死）
  → 都不可用时**直接报错终止**，不再产出无图标的 exe；
- CI 安装 go-winres，并在构建后做**两道硬校验**：`.syso` 必须存在且非空、**PE 资源目录里必须真有 `RT_GROUP_ICON`**
  （只查 `.syso` 防不住「生成了但没被链接」）；
- 实测对比：线上 0.9.6 exe 资源目录 `RVA=0x0 Size=0`（无资源）、本地新构建含
  `RT_ICON / RT_GROUP_ICON / RT_VERSION / RT_MANIFEST`，版本属性 `0.9.7 / CFPilot`。

## 优化

- **KV 清单读取改为并发 4 路**：每个 KV 命名空间都要读一遍部署清单，串行时 6 个命名空间实测
  20~25 秒（凭据页一打开就触发，很像假死）。并发后 12 个命名空间的单测从 2.9s 降到 0.86s，
  真机检测从 25 秒降到 15 秒内；返回顺序与列表接口一致（结果按下标写回）。
- 顺手把 `/api/kv/list`、`/api/kv/create` 的 Cloudflare 客户端统一到 `newCFClient()`（生产行为不变，
  但测试可以注入假 API，才补得上上面这条并发回归测试）。
