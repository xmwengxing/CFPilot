## 新增

- **版本说明**：本版本为 0.60.0-beta.1 测试版（首次引入异地组网与盲中继模块），**转发内核（控制面 + 数据面）始终保持正式版升级形态**，不影响既有代理实例，可放心更新部署
- 新增 **盲中继 / 云监测台** 一键部署与已部署实例检测（普通版、+mesh 版桌面端与 CLI 均支持），支持域名自动匹配、自定义监测台密码、一键回填组网配置，以及只读设备在线状态监测面板
- 新增 **+mesh 异地组网模块**：无公网 IP 设备可通过 Cloudflare 边缘盲中继完成发现与保底连通，基于 Noise IKpsk2 + ChaCha20-Poly1305 端到端加密（中继全程不解密业务数据）
- 异地组网支持智能选路与全链路打洞：STUN NAT 探测、UDP P2P 直连优先、中继会话后自动协同打洞升级直连、对称 NAT 端口探测、链路劣化自动降级 WSS 盲中继或专用服务器中继，恢复后自动回切，并支持节点间中继转发与广播扇出
- 异地组网支持 **专用服务器中继部署闭环**：界面一键生成自包含服务器部署命令（含预生成令牌与 systemd 服务），粘贴初始化输出即可自动回填，并支持零知识盲中继准入模式
- 异地组网支持 **邀请链接一键入网** 与 **多网络配置档案**：自动生成并持久化节点身份密钥，一端生成邀请链接（自动携带网络名、PSK、盲中继与云监测台配置），其余设备粘贴即可加入并经 Gossip 双向自动发现
- 桌面端新增 **组网页** 与 **实时网络拓扑视图**：可视化展示节点连通状态、RTT、丢包与实时流量脉冲，支持启停按钮状态机与云监测心跳上报配置
- 优选页新增 **「组网入口」页签**：面向盲中继的专用 WSS 握手延迟探测，支持带端口候选、内置候选源与本地文件导入，探测结果可一键填入组网配置
- 新增 **+mesh 全平台发行矩阵**：Windows 提供现代中文安装向导（支持自定义路径、自动注册提权组网服务并联网下载校验 wintun.dll）、Linux 提供 amd64 / arm64 `.deb` 安装包（含 systemd 守护服务）、Android 提供基于 VpnService 的独立组网客户端，CLI 同步提供 `cfpilot-mesh` 包
- 桌面版新增 **原生应用窗口**：Windows（WebView2 无边框自绘标题栏）与 Linux（WebKitGTK，缺失时自动回退系统浏览器）直接以独立窗口打开管理面板，关闭窗口后托盘常驻运行
- 转发内核默认同时下发 **VLESS + WS** 与 **VLESS + XHTTP（packet-up）** 双形态订阅节点，Clash（mihomo 1.19+）可直接识别 XHTTP 节点
- 转发内核新增 **反代入口自愈与动态保活清单**：自动识别老化反代返回的 TLS 致命告警并立即切换入口，按域名记忆已确认收到真实下行的有效出口，同时后台低频刷新动态双通清单，零手配即可稳定访问 Cloudflare 网段站点与 X（网页与手机 App）
- 说明页新增三套默认折叠的快速上手教程（盲中继 / 云监测台、异地组网、代理实例部署）

## 修复

- 修复转发内核中老化反代入口返回 TLS 致命告警时被误判为通路建立并锁入成功记忆，导致 X 网页与手机 App 无法打开的问题
- 修复固定反代入口失效时无冷却导致每次请求重复等待超时的问题，并将出厂固定反代改为面板可选「填入建议值」（默认不写死单点）
- 修复单连接流量熔断关闭码（改用 1013），避免客户端将流量限额熔断误判为节点死亡
- 修复转发内核 DNS 解析、拨号记账、入站生命周期及诊断时钟统计异常
- 修复订阅响应头携带空流量信息导致部分客户端显示 0 B / 1970 的问题
- 修复优选地区筛选在东亚地区混入无效 IPv6 候选及零命中时放宽为全量机房的问题
- 修复盲中继部署前置卡点：账号 ID 缺失自动探测、Zone 自动匹配与手动填写支持、DNS 检查非阻塞以及域名冲突与 D1 复用自愈
- 修复异地组网多处链路与交互问题：中继腿误判直连、本网虚拟 IP 混入候选、中继重启后未重试注册、空闲期误报断线、双栈监听与手工外网地址支持、安装升级时自动替换并重建组网服务
- 修复 Android 管理版凭据页新增第二个账户偶发「获取账号失败」以及删除凭据时确认弹窗无响应、账户列表不刷新的问题
- 修复桌面版优选页在优选进行中切换页面再切回后进度条消失的问题
- 修复桌面版更新检查与提示逻辑：明确标注测试版与正式版、解决内核部署更新提示不消失及普通版与 +mesh 版更新包匹配冲突的问题

## 优化

- 桌面版所有折叠区（含优选流程说明与优选历史）标题行增加凹凸立体层次与展开状态徽标，展开后更易识别并一键收起
- 桌面端与 Android 端组网表单精简为「必填项 + 高级选项」两层结构，说明收进悬浮气泡，并增加防连点状态机
- 转发内核出厂反代入口池剔除全部失效与受限 IP，默认单连接流量熔断调整为 512 MB、假活重拨上限调整为 2 轮，降低免费版 CPU 超限风险（更新部署自动迁移旧默认值）
- 桌面版切页自动记忆各页面滚动位置，弹窗悬浮提示改用纯 CSS 实现并在卸载时增加进程占用防护
- 桌面版应用更新下载校验与免 API 通道兼容预发布版本号，普通版与 +mesh 版产物共存于同一发行版互不干扰
