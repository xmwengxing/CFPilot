## 新增

- 出厂内置一批实测可用的反代入口兜底：零配置即可稳定访问 Cloudflare 网段站点（含 X 手机 app）
- 反代优选终检升级：逐个校验网址实测转发，被站点边缘规则拦截的入口自动剔除
- 应用更新自动化：检查更新后自动下载到缓存，下载完成出现「重启并更新应用」按钮，一键替换主程序并重启
- 面板「自定义反代入口池 / 固定落地 IP」只显示自己填写的条目，出厂兜底隐形生效

## 修复

- 修复 X 手机 app 无法加载内容的问题（部分反代出口被站点边缘规则拦截，现已自动避开）

## 优化

- 反代优选校验网址新增 api.x.com，更准确筛出可用入口
- 出厂兜底条目不固化进用户配置，入口失效更换时自动跟随内核更新
