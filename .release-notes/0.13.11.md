# CFPilot v0.13.11

## 新增

- Workers 形态部署时读取数据面已绑定的自定义域名，可直接用作节点域名
- 部署前校验节点域名，串到控制面或账号里其他 Worker 时会拒绝部署并说明原因

## 优化

- Workers 形态配置了自定义域名时，自动关闭 workers.dev 的生产链接与预览链接
- 数据面部署形态在切换账户时复位，不再沿用上一个账户的选择

## 修复

- 修复切换账户后节点域名残留上一个账户的值、被写进控制面 DATA_HOST 导致节点全部失效的问题
- 修复 Workers 形态未关闭 workers.dev 生产与预览链接时节点全部失效的问题
