使用说明

1. 在「入站配置」确认 UUID / Trojan 密码与路径；
2. 在「优选池」填入 ADD / ADDAPI / ADDCSV，或用「一键优选」跑一次本地真连接扫描；
3. 在「订阅」复制 Clash / Sing-box / Base64 订阅链接导入客户端；
4. 客户端节点里的 server 是优选 IP，sni / Host 固定为你的 Worker 域名 —— 这正是避免 -1 超时的关键。
