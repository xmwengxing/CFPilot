# CFPilot v0.13.8

## 新增

- 优选页新增「自适应效果对照」，同档案同域名下可比较开启与关闭自适应采样的分阶段通过率
- 优选页新增网络档案状态卡，显示当前档案、各阶段样本量与最后更新时间
- 优选页新增网络档案管理，可修正地区与删除档案
- 优选结果标注本轮是否使用了自适应采样
- 历史会话记录分阶段统计，可用于对照分析
- CLI 与桌面版新增跨端一致性校验夹具

## 优化

- 优选器与桌面版的自适应采样内核对齐为同一套实现，常量、公式与采样策略逐位一致
- 观测回写补齐 TCP 与 TLS 阶段，不只记录最终握手结果
- 地区名归一化，「福建」「福建省」「闽」等写法归入同一档案
- CLI 与桌面版共用同一份网络档案文件，样本可以互相看到
- 档案库按 /24 粒度学习权重，避免不同网段互相污染
- README「技术实现」改写为折叠表格，逐项列出内核与优选器采用的技术方法

## 修复

- 修复自适应采样的观测查不到、权重实际未生效的问题
- 修复 IPv6 网段下自适应采样内存暴涨的问题
- 修复网段池较小时候选数取不满的问题
- 修复删除重复的采样实现导致两端行为不一致的问题
- 修复档案地区写法不同被拆成多个档案的问题
