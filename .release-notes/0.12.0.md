# CFPilot v0.12.0

## 桌面版：优选结果历史列表（留底 / 多选复制 / 二次复测）

- 每次优选成功（本地真连接优选 / 一键优选）自动留底到「优选历史」，保留最近 30 次，跨天可对比。
- 展开任意一次结果，勾选任意 IP：
  - **复制选中 IP** —— 生成 `IP:Port#机房` 列表，直接粘回面板「手动优选 IP」；
  - **复测选中** —— 按 TCP → TLS 握手 → WebSocket 101 分层校验，能看出是哪一层挂了；
    勾选「带测速」可同时重新测下行速度。
- 复测使用该次会话保存的域名与 WS 路径（不受当前表单影响），复测结论自动写回历史条目。

## 界面

- 「开始优选」上方的流程说明重写为完整四阶段描述（TCP 初筛 → TLS 筛选 → 两层校验 → 稳态测速），
  并默认折叠为「优选IP流程说明」，需要时再展开查看，不再占用页面空间。
