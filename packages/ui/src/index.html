🚀 部署 / 更新

Pages 双项目：控制面（面板 + 订阅 + 探针）+ 数据面（代理入站），共用同一个 KV。

自动判断：KV 中有部署记录则更新，没有则新建 —— 通常无需修改此项。
更新现有部署：沿用原 UUID 与 WS 路径，客户端订阅地址无需变更。
全新部署：忽略旧记录，重新创建项目并生成新实例 —— 需要一个未被占用的 KV（在「凭据」页新建）。
⚠ 选中已有实例的 KV 会被直接拦截并提示 —— 全新部署会生成新的 UUID 与 WS 路径，覆盖原 KV 的话， 原实例的客户端节点将全部失效。确需接管请启用「覆盖 KV 归属校验」。

部署完成后，密码会显示在日志中（面板密码在云端加密，事后无法再读取）。

🔗 链式代理（自建落地节点）

在你自己的 VPS 上装一个带口令的 SOCKS5 落地节点， 让流量走 客户端 → Worker → VPS → 目标站。 这样目标站看到的是你的 VPS 出口，而不是 Cloudflare 的机房 IP。 



            

              · 需要本机有 ssh 客户端（Windows 10+ 自带）且已配好密钥。

              · 没有密钥也能用：点「复制命令」在终端里执行 —— 终端里 ssh 才会提示输入密码。

              · 脚本会装 sing-box、生成随机口令、起 systemd 服务，仅支持 Debian/Ubuntu/CentOS 系。

              · 跑完会打印一行 socks5://用户:口令@IP:端口，粘到面板「出站与高级」→ SOCKS5。

📘 功能说明

            

              CFPilot 的图形化部署与维护工具。功能与命令行版
              cfpilot deploy / cfpilot scan 一致，
              适合不接触命令行的用户。
            

            

              部署流程

              1. 在「凭据」页填写 Token 并保存，点击「检测账号」，再点击「刷新 KV 列表」

              2. 在下拉框中选择一个 KV（带 ● 的是已有实例），切换到「部署」页点击「开始部署」

              3. 在「优选」页填入上一步得到的数据面域名，执行一次优选，并把结果填入面板的「手动优选 IP」

              4. 优选 IP 可能失效，节点不稳定时可再次执行优选，无需每日进行


              更新升级

              选择「更新现有部署」：选择同一个 KV，工具识别本项目并复用 UUID 与 WS 路径，
              客户端订阅地址保持不变。


              关于 CFPilot

              CFPilot 采用双 Pages 项目部署一对实例：控制面（Web 面板）+ 数据面（流量转发），
              实测稳定无 1101，支持在触发 CF 限制时进行更新部署

              不建议在同一账户下部署多个 CFPilot 实例；若确需部署：创建新的 KV，选择该 KV 后部署第二对实例

              本项目暂不支持 Worker 形式部署
            

          


          

            
🔒 安全说明

            

              API Token 与面板密码仅写入本机
              ~/.cfpilot-gui/secrets.json，不会上传到任何服务器，
              也不随安装包分发。


              工具的出境网络请求仅三类：

              · api.cloudflare.com —— 部署必需，令牌仅用于该请求的 Authorization 头

              · 你自己的域名 —— 优选阶段的 101 握手校验

              · 你主动点击的官方链接 —— 以系统浏览器打开


              不存在「把令牌发到第三方」的路径。可随时点击「删除本地账号/凭据」清除。

❓ 常见问题

            

              面板无法打开？面板路径是随机生成的，部署日志中会打印。


              优选结果全是 -1？检查域名与 WS 路径是否与客户端一致，端口是否为 443 等 TLS 端口。


              提示「版本相同已跳过」？说明线上已是最新版本，无需重新部署；确需强制更新请启用「强制重新部署」。


              部署失败？查看下方日志中的具体错误；权限问题可对照「凭据」页的权限说明。
