## 新增

- 优选「两轮测速」：WS 101 校验通过的全部候选先做 1.2 秒短测粗排，再对速度最好的 30 个做 6 秒完整精测，避免「握手稍慢但下行更快」的 IP 被延迟排序截掉；界面开关默认开启，关闭即回到旧行为
- 粗筛带候选上限（120）与 4 分钟总预算，到点后剩余候选按延迟兜底；粗测数值只用于排序，不写进结果，对外速度仍来自精测
- CLI 新增 `--two-stage-speed` 与 5 个粗筛参数（默认关闭，自动化脚本行为不变），Go 版按同一份语义对齐
- 静态校验新增「SSE 事件订阅表完整性」与「新建账户归属」两组断言，纳入 `npm run verify`

## 优化

- 优选总进度条拆出「全量粗筛」档（45–55%），且只在一次优选期间响应日志，进度不会倒退
- 粗筛日志按 5 个一批节流，避免长轮次把日志窗口刷屏
- 优选失败结果（无 entries）时进度条收尾不再抛异常

## 修复

- 凭据页选「＋ 新建账户」、填 Token 点「添加并保存」后，「当前使用」自动选中新账户（此前一直停在「＋ 新建账户」）
- 每次启动日志里的「初始化「反代优选」失败：Cannot read properties of undefined (reading 'push')」；同时补齐 relay-result / relay-progress 两类 SSE 事件，反代体检的进度与结果推送不再丢失
- 优选结束后点「增量回填 / 覆盖回填」，进度条被取令牌日志重新算成 1%；现在回填完全不触碰进度条
