# CFPilot v0.13.2

## 新增

- 目标地址策略（P1）：直连与优选 IP 不再连向环回、私网、链路本地、CGNAT、组播与内网域名；
  配置了 SOCKS5 / HTTP 代理时照常走代理，代理本身不受影响
- 失败原因新增「被目标地址策略拒绝」分级，与「被平台拒绝」可分
- 桌面版「全新部署」自动新建独立的 KV 命名空间，不再复用「Cloudflare 凭据」页选中的那个
- 优选测速的连接数上限从 8 提到 16，跨境链路吞吐不再被单连接低估

## 优化

- 上行写入串行化（P0）：重拨期间换连接、重放缓存与补写合并为一次原子操作，
  不再因为帧顺序错乱导致 TLS 握手/解密失败
- 测速稳态口径对齐：丢弃慢启动样本后按时间加权计算，零字节窗口不再拉低结果
- 部署与优选的状态提示：请求受理后显示「进行中」，结果由实时推送给出

## 修复

- 点击部署时状态栏先闪「部署失败」再变成功（受理响应被当成了最终结果）
- 优选状态栏在任务刚开始时显示「优选失败：」
- 全新部署原提示称「会覆盖原 KV」，与实际行为不符 —— 覆盖原 KV 的是带「重新生成凭据」的更新部署
- HTTPS / SOCKS5 代理建连成功后超时定时器未清理
- SOCKS5 代理对 IPv6 目标地址缺少握手超时，代理不回应时会一直挂着
