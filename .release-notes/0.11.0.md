## 新增

- 桌面版优选页的「机房国家」改为快捷分组选择（全部国家 / 亚洲组 / 美国组），并新增「自定义配置」弹窗：支持搜索、按大洲分组勾选、全选与清空
- 命令行 `--countries` 支持机房三字码（如 `HKG` 自动归一到 `HK`），与桌面版行为一致

## 修复

- 桌面版「需要的 Token 权限」说明更正为与实际部署路径一致：不再把 Workers Scripts 列为必需项，并补充可选项
- 诊断端点只接受完整 UUID，并对失败尝试限速
- XHTTP 协议头读取超时后不再残留后台读取任务
- 命令行与桌面版的国家筛选单位不一致（桌面版传机房码、命令行只认国家码）已统一为国家码

## 优化

- 桌面版界面最大宽度 1060 → 1160，机房国家控件与同排输入框等高，优选页可视区域更大
- 面板密码改用 PBKDF2 存储，旧实例登录时自动升级；登录失败按来源 IP 限速
- `/__edge_probe` 增加实例级流量预算，超出返回 429
- 远程内核与桌面版安装包更新增加 SHA-256 完整性校验
- 优选自适应并发不再超过用户设定的并发数
