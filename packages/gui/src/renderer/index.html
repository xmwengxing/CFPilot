工具运行时的出境网络请求只有：
· api.cloudflare.com（部署功能必需，令牌仅用于该请求的 Authorization 头）
· 优选阶段访问你自己的域名做 101 校验
· 你主动点击的官方链接（用系统浏览器打开）

点「清除本机凭据」可随时删除。

你的代理域名（数据面的地址）。检查更新后会自动填入。 用它做 TLS SNI 与 HTTP Host，才能测出真实可用性。

必须与客户端填的端口一致，否则结果无效。

📘 这是什么

CFPilot 的图形化部署与维护工具。功能与命令行版 cfpilot-deploy / cfpilot-scanner 相同， 适合不想碰终端的用户。

三步部署
1. 在「Cloudflare 凭据」页填 Token 并保存，点「自动检测账号与 KV」
2. 在「一键部署」页点「开始部署」
3. 在「本地真连接优选」页填上一步得到的数据面域名，跑一次优选，把结果粘贴到面板的「手动优选 IP」

更新升级
再跑一次「开始部署」即可：工具认得自己的项目，会沿用 UUID 与 WS 路径， 客户端订阅地址不用改。

🔒 安全说明

API Token 与面板密码只写在本机 ~/.cfpilot-gui/secrets.json，不会上传到任何服务器， 也不随安装包分发。

工具的出境网络请求只有三类：
· api.cloudflare.com —— 部署必需，令牌仅用于该请求的 Authorization 头
· 你自己的域名 —— 优选阶段的 101 握手校验
· 你主动点击的官方链接 —— 用系统浏览器打开

不存在「把令牌发到第三方」的路径。随时可点「清除本机凭据」删除。

❓ 常见问题

面板打不开？面板路径是随机生成的，部署日志里会打印。

优选结果全是 -1？检查域名与 WS 路径是否和客户端一致，端口是否为 443 等 TLS 端口。

提示「版本相同已跳过」？说明线上已是最新版本，无需重新部署；需要强制更新就勾选「强制重新部署」。

部署失败？看下方日志里的具体错误；权限问题可对照「凭据」页的权限说明。
