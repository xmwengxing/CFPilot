## 新增

- 数据源页支持按名称、ID 或链接搜索，并按域名源、IP / API 源、参与同步状态、内置 / 自定义分类筛选
- 来源清单支持一次勾选多个条目，批量设为参与同步、暂停同步或删除，并显示已选数量
- 「加载数据源清单」弹窗可勾选任意来源作为候选地址，不要求该来源参与同步

## 修复

- 自定义列表模式下「候选采样数」「地址族」原本可以填写却不生效，现在会置灰并说明原因；实验性采样设置也会提示本次不参与
- 「立即同步」在没有来源参与同步时看起来没有反应，现在按钮旁会显示参与同步的来源数量，并在为零时提示需要先勾选
- 数据源开关的文案统一为「参与同步」，避免被误解成来源能否被选用的总开关

## 优化

- 来源清单默认折叠成一行概览，展开后限高内部滚动且表头吸顶，不再把采集记录与本地候选池挤到页面外
- 新增或编辑来源改为一次保存即生效，批量操作同样即时保存
- 桌面版构建不再清理整个产物目录，避免有程序正在运行时构建失败
