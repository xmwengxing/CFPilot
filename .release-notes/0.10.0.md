## 新增

- 桌面版优选页签的「机房国家」新增三个筛选器：取消选择（不选 = 全部）、亚洲组、美国组，两个分组可以同时选中
- 命令行版同步支持这三个选项：地区选择菜单里的同名三项，以及 `--countries ASIA,US` 分组关键字
- 可选的数据面单连接流量熔断：配置项 `dataBudgetMB`（KV 或环境变量 `DATA_BUDGET_MB`，默认 `0` 表示不限制），超限后主动断开该连接，避免单条大流量会话吃光账号的 CPU 配额

## 修复

- 反代重拨期间客户端继续发送的数据不再丢失（此前这些数据收不到处理，表现为切换反代后隧道静默挂起直到超时）
- 反代重拨不再误关整个会话，也不再残留旧连接长期占用单请求的出站并发额度
- XHTTP 下行正常结束时关闭出站连接，不再长期占用出站并发额度

## 优化

- 协议解析热路径减少内存分配：UUID 校验不再生成十六进制字符串，编解码器改为复用
